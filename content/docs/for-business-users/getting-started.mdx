## Getting Started

### Step 1: Create a Spark

A **Spark** is your workspace — a container for everything related to a topic, project, or campaign. From the dashboard, click **New Spark** and give it a name and description.

Good Spark names describe the intent:
- "Q2 Product Launch Campaign"
- "Competitor Analysis — Enterprise CMS"
- "Blog Content Calendar — March 2025"
- "Customer Feedback Synthesis"

The description helps the AI understand context, so be specific: "Research and planning for the Q2 launch of our headless CMS product targeting enterprise customers" is better than "Q2 stuff."

### Step 2: Collect Items

Once inside your Spark, you can add items using the **+ Add Item** button. Each item type captures different kinds of information:

| Type | What It Does |
|------|-------------|
| **Link** | Paste a URL — Spark scrapes the page title, description, images, and full text content |
| **Image** | Upload an image — AI analyzes it for OCR text, objects, and scene description |
| **Text** | Paste raw text content |
| **Note** | Write a Markdown note with formatting |
| **File** | Upload any document |

### Step 3: Connect Integrations

For richer data collection, connect your external services:

- **Contentstack** — Import entries and assets from your CMS stacks
- **Google Drive** — Pull in documents, spreadsheets, and presentations
- **Slack** — Save relevant thread conversations

Click the integrations panel in the Spark header to connect services via OAuth.

### Step 4: Chat with Your Data

Open the **Chat** panel and start asking questions. The AI has already read and indexed everything in your Spark. Try:

- "What are the key themes across these articles?"
- "Summarize the competitive landscape based on what I've collected"
- "Draft a blog post outline using the research I've gathered"
- "What gaps do I have in my research?"

### Step 5: Generate Artifacts

When you're ready to create output, use the **Generate** panel or ask the AI directly:

- "Generate a CMS entry for a blog post about [topic]"
- "Create a campaign brief based on my research"

The AI will synthesize your collected items into structured, business-ready content.

### Tips for Power Users

- **Use @ mentions** — Type `@` in the chat to reference specific items by name. The AI will give these items extra attention.
- **Select on canvas, then chat** — Select items on the visual canvas and open the chat panel. The AI will focus exclusively on those selected items.
- **Highlight text in the editor** — Select text in the document editor before chatting. The AI can suggest rewrites and improvements.
- **Check the activity log** — The lightning bolt icon shows every API call the system makes, useful for understanding what the AI is doing.
